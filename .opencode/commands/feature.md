Implement this feature:

$ARGUMENTS

Process:

1. Understand the requirement.
2. Inspect only relevant files.
3. Identify the frontend, backend and database changes required.
4. Implement the smallest complete solution.
5. Reuse existing components and utilities.
6. Run relevant typechecks/tests.
7. Fix failures caused by the implementation.
8. Review the final diff.
9. Summarize changed files and verification.

Do not redesign unrelated parts of the application.

Do not add dependencies unless necessary.

Do not introduce PostgreSQL or any database technology other than SQLite + Prisma.

If the feature crosses frontend/backend/database boundaries, implement all required layers.
